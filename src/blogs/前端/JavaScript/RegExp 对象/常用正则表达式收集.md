::: tip <Badge text="概述" type="tip"/>

## 一、数字类 <Badge text="数字验证" type="success"/>

### 1. 数字

```javascript
/^[0-9]*$/
```

### 2. n位的数字

```javascript
/^\d{n}$/
```

### 3. 至少n位的数字

```javascript
/^\d{n,}$/
```

### 4. m-n位的数字

```javascript
/^\d{m,n}$/
```

### 5. 零和非零开头的数字

```javascript
/^(0|[1-9][0-9]*)$/
```

### 6. 非零开头的最多带两位小数的数字

```javascript
/^([1-9][0-9]*)+(.[0-9]{1,2})?$/
```

### 7. 带1-2位小数的正数或负数

```javascript
/^(\-)?\d+(\.\d{1,2})?$/
```

### 8. 正数、负数、和小数

```javascript
/^(\-|\+)?\d+(\.\d+)?$/
```

### 9. 有两位小数的正实数

```javascript
/^[0-9]+(.[0-9]{2})?$/
```

### 10. 有1~3位小数的正实数

```javascript
/^[0-9]+(.[0-9]{1,3})?$/
```

### 11. 非零的正整数

```javascript
/^[1-9]\d*$/ 或 /^([1-9][0-9]*){1,3}$/ 或 /^\+?[1-9][0-9]*$/
```

### 12. 非零的负整数

```javascript
/^\-[1-9][]0-9"*$/ 或 /^-[1-9]\d*$/
```

### 13. 非负整数

```javascript
/^\d+$/ 或 /^[1-9]\d*|0$/
```

### 14. 非正整数

```javascript
/^-[1-9]\d*|0$/ 或 /^((-\d+)|(0+))$/
```

### 15. 非负浮点数

```javascript
/^\d+(\.\d+)?$/ 或 /^[1-9]\d*\.\d*|0\.\d*[1-9]\d*|0?\.0+|0$/
```

### 16. 非正浮点数

```javascript
/^((-\d+(\.\d+)?)|(0+(\.0+)?))$/ 或 /^(-([1-9]\d*\.\d*|0\.\d*[1-9]\d*))|0?\.0+|0$/
```

### 17. 正浮点数

```javascript
/^[1-9]\d*\.\d*|0\.\d*[1-9]\d*$/ 或 /^(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*))$/
```

### 18. 负浮点数

```javascript
/^-([1-9]\d*\.\d*|0\.\d*[1-9]\d*)$/ 或 /^(-(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*)))$/
```

### 19. 浮点数

```javascript
/^(-?\d+)(\.\d+)?$/ 或 /^-?([1-9]\d*\.\d*|0\.\d*[1-9]\d*|0?\.0+|0)$/
```

## 二、字符类 <Badge text="字符验证" type="success"/>

### 1. 汉字

```javascript
/^[\u4e00-\u9fa5]{0,}$/
```

### 2. 英文和数字

```javascript
/^[A-Za-z0-9]+$/ 或 /^[A-Za-z0-9]{4,40}$/
```

### 3. 长度为3-20的所有字符

```javascript
/^.{3,20}$/
```

### 4. 全英文字母组成的字符串

```javascript
/^[A-Za-z]+$/
```

### 5. 全大写英文字母组成的字符串

```javascript
/^[A-Z]+$/
```

### 6. 全小写英文字母组成的字符串

```javascript
/^[a-z]+$/
```

### 7. 数字和英文字母组成的字符串

```javascript
/^[A-Za-z0-9]+$/
```

### 8. 数字、英文字母或者下划线组成的字符串

```javascript
/^\w+$/ 或 /^\w{3,20}$/
```

### 9. 中文、英文、数字包括下划线

```javascript
/^[\u4E00-\u9FA5A-Za-z0-9_]+$/
```

### 10. 中文、英文、数字但不包括下划线等符号

```javascript
/^[\u4E00-\u9FA5A-Za-z0-9]+$/ 或 /^[\u4E00-\u9FA5A-Za-z0-9]{2,20}$/
```

### 11. 可以输入含有^%&',;=?$\"等字符

```javascript
/[^%&',;=?$\x22]+/
```

### 12. 禁止输入含有~的字符

```javascript
/[^~\x22]+/
```

## 三、特殊及常用需求类 <Badge text="常用场景" type="success"/>

### 1. Email地址

```javascript
/^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$/
```

### 2. 域名

```javascript
/[a-zA-Z0-9][-a-zA-Z0-9]{0,62}(\.[a-zA-Z0-9][-a-zA-Z0-9]{0,62})+\.?/
```

### 3. URL

```javascript
/[a-zA-z]+:\/\/[^\s]*$/ 或 /^http:\/\/([\w-]+\.)+[\w-]+(\/[\w-./?%&=]*)?$/
```

### 4. 手机号码

```javascript
/^(13[0-9]|14[5|7]|15[0|1|2|3|5|6|7|8|9]|18[0|1|2|3|5|6|7|8|9])\d{8}$/
```

### 5. 电话号码
"XXX-XXXXXXX"、"XXXX-XXXXXXXX"、"XXX-XXXXXXX"、"XXX-XXXXXXXX"、"XXXXXXX"和"XXXXXXXX"
```javascript
/^(\(\d{3,4}-)|\d{3.4}-)?\d{7,8}$/
```

### 6. 国内电话号码
0511-4405222、021-87888822
```javascript
/\d{3}-\d{8}|\d{4}-\d{7}/
```

### 7. 身份证号
15位、18位数字
```javascript
/^\d{15}|\d{18}$/
```

### 8. 短身份证号码
数字、字母x结尾
```javascript
/^([0-9]){7,18}(x|X)?$/ 或 /^\d{8,18}|[0-9x]{8,18}|[0-9X]{8,18}?$/
```

### 9. 帐号是否合法
字母开头，允许5-16字节，允许字母数字下划线
```javascript
^[a-zA-Z][a-zA-Z0-9_]{4,15}$
```

### 10. 密码
以字母开头，长度在6~18之间，只能包含字母、数字和下划线
```javascript
/^[a-zA-Z]\w{5,17}$/
```

### 11. 强密码
必须包含大小写字母和数字的组合，不能使用特殊字符，长度在8-10之间
```javascript
/^(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,10}$/
```

### 12. 日期格式

```javascript
/^\d{4}-\d{1,2}-\d{1,2}/
```

### 13. 空白行的正则表达式
可以用来删除空白行
```javascript
/\n\s*\r/
```

### 14. HTML标记的正则表达式
网上流传的版本太糟糕，上面这个也仅仅能部分，对于复杂的嵌套标记依旧无能为力
```javascript
/<(\S*?)[^>]*>.*?<\/\1>|<.*? \/>/
```

### 15. 首尾空白字符的正则表达式
可以用来删除行首行尾的空白字符(包括空格、制表符、换页符等等)，非常有用的表达式
```javascript
/^\s*|\s*$/ 或 /(^\s*)|(\s*$)/
```

### 16. 腾讯QQ号
腾讯QQ号从10000开始
```javascript
/[1-9][0-9]{4,}/
```

### 17. 中国邮政编码
中国邮政编码为6位数字
```javascript
/[1-9]\d{5}(?!\d)/ 
```

### 18. IP地址
提取IP地址时有用
```javascript
/\d+\.\d+\.\d+\.\d+/ 
```

### 19. IP地址 (更精确)

```javascript
/((?:(?:25[0-5]|2[0-4]\d|[01]?\d?\d)\.){3}(?:25[0-5]|2[0-4]\d|[01]?\d?\d))/
