## 1. `Array.prototype.sort()` <Badge text="内置方法" type="success"/>

JavaScript数组内置的 `sort()` 方法用于对数组的元素进行原地排序，并返回数组。默认情况下，`sort()` 方法将按字母顺序对元素进行排序，将值视为字符串。

**注意**：`sort()` 方法会改变原始数组。

如果需要按照数字大小或其他自定义顺序进行排序，必须提供一个**比较函数**。该函数接收两个参数 `a` 和 `b`，并根据它们的相对顺序返回一个数字：

*   如果 `a - b` 返回负数，表示 `a` 应该排在 `b` 之前（升序）。
*   如果 `a - b` 返回正数，表示 `a` 应该排在 `b` 之后（降序）。
*   如果 `a - b` 返回零，表示 `a` 和 `b` 的相对位置不变。

```javascript
var arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9];

// 升序排序
arr.sort((a, b) => {
  return a - b; // 升序，如果数组元素是对象，可以使用 a.value - b.value
});
console.log(arr);
// 输出: [1, 2, 4, 6, 6, 9, 15, 19, 23, 28]

// 降序排序
arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9]; // 重置数组
arr.sort((a, b) => {
  return b - a; // 降序
});
console.log(arr);
// 输出: [28, 23, 19, 15, 9, 6, 6, 4, 2, 1]
```

## 2. 冒泡排序 (Bubble Sort) <Badge text="简单" type="info"/>

**定义**：冒泡排序是一种简单的排序算法。它重复地遍历待排序的列表，比较每对相邻元素，如果它们的顺序错误就把它们交换过来。遍历列表的工作是重复进行的，直到没有再需要交换，也就是说该列表已经排序完成。

**原理**：每一趟遍历都会将当前未排序部分的最大（或最小）元素“冒泡”到其最终位置。

```javascript
var arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9];

function bubbleSort(arr) {
  const len = arr.length;
  for (let i = 0; i < len - 1; i++) { // 外层循环控制趟数
    for (let j = 0; j < len - 1 - i; j++) { // 内层循环进行比较和交换
      // 如果前一个元素比后一个大，则交换位置
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; // ES6解构赋值交换
      }
    }
  }
  return arr;
}
console.log(bubbleSort(arr));
// 输出: [1, 2, 4, 6, 6, 9, 15, 19, 23, 28]
```

## 3. 选择排序 (Selection Sort) <Badge text="原地排序" type="info"/>

**定义**：选择排序是一种简单直观的排序算法。它的工作原理是：第一次从待排序的数据元素中选出最小（或最大）的一个元素，存放在序列的起始位置，然后再从剩余的未排序元素中寻找到最小（或最大）元素，然后放到已排序的序列的末尾。以此类推，直到全部待排序的数据元素的个数为零。

**原理**：每一趟遍历都会从当前未排序部分中找到最小（或最大）的元素，并将其放到已排序部分的末尾。

```javascript
var arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9];

function selectionSort(arr) {
  const len = arr.length;
  let minIndex;
  for (let i = 0; i < len - 1; i++) {
    minIndex = i; // 假设当前元素是最小的
    for (let j = i + 1; j < len; j++) {
      if (arr[j] < arr[minIndex]) { // 找到更小的元素
        minIndex = j;
      }
    }
    // 如果最小元素不是当前位置的元素，则交换
    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]]; // ES6解构赋值交换
    }
  }
  return arr;
}
console.log(selectionSort(arr));
// 输出: [1, 2, 4, 6, 6, 9, 15, 19, 23, 28]
```

## 4. 快速排序 (Quick Sort) <Badge text="高效" type="success"/>

**定义**：快速排序是一种高效的、基于比较的排序算法，通常比其他O(n²)算法快得多。它采用分治法（Divide and Conquer）的策略。

**原理**：
1.  **选择基准 (Pivot)**：从数组中选择一个元素作为“基准”（pivot）。
2.  **分区 (Partition)**：重新排列数组，使得所有小于基准的元素都移到基准的左边，所有大于基准的元素都移到基准的右边。基准元素现在处于其最终的排序位置。
3.  **递归 (Recursion)**：递归地对左右两个子数组进行快速排序。

```javascript
var arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9];

function quickSort(arr) {
  if (arr.length <= 1) { // 递归基线条件
    return arr;
  }

  const pivotIndex = Math.floor(arr.length / 2);
  const pivot = arr.splice(pivotIndex, 1)[0]; // 选取基准并从原数组中移除

  const left = [];
  const right = [];

  for (let i = 0; i < arr.length; i++) {
    if (arr[i] < pivot) {
      left.push(arr[i]);
    } else {
      right.push(arr[i]);
    }
  }

  return quickSort(left).concat(pivot, quickSort(right));
}
console.log(quickSort(arr));
// 输出: [1, 2, 4, 6, 6, 9, 15, 19, 23, 28]
```

## 5. 插入排序 (Insertion Sort) <Badge text="稳定" type="info"/>

**定义**：插入排序是一种简单直观的排序算法。它的工作原理是通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。

**原理**：将数组分为已排序和未排序两部分。每次从未排序部分取出一个元素，插入到已排序部分的正确位置，直到未排序部分为空。

```javascript
var arr = [19, 6, 4 , 6, 15, 28, 23, 2, 1, 9];

function insertionSort(arr) {
  const len = arr.length;
  let preIndex, current;
  for (let i = 1; i < len; i++) {
    preIndex = i - 1; // 已排序部分的最后一个元素的索引
    current = arr[i]; // 待插入的元素

    // 在已排序部分从后向前查找插入位置
    while (preIndex >= 0 && arr[preIndex] > current) {
      arr[preIndex + 1] = arr[preIndex]; // 元素后移
      preIndex--;
    }
    arr[preIndex + 1] = current; // 插入待排序元素
  }
  return arr;
}
console.log(insertionSort(arr));
// 输出: [1, 2, 4, 6, 6, 9, 15, 19, 23, 28]
```
