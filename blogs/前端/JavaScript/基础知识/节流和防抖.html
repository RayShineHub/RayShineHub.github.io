知识篇 -- JS节流与防抖

知识篇 -- JS节流与防抖

在前端开发中，节流（Throttling）和防抖（Debouncing）是两种常用的性能优化技术，用于控制高频事件（如鼠标重复点击、页面滚动、鼠标拖拽、Input框自动填充、文档编辑保存等）的执行频率。它们虽然都能防止事件的重复触发，但在实现机制和适用场景上有所不同。

理解并正确运用节流和防抖，对于提升用户体验和减轻服务器压力至关重要。

# 防抖（Debounce） 只执行一次

# 定义

防抖的核心思想是“等一个有效指令”：在事件被触发后，设定一个固定延迟时间。如果在该延迟时间内事件再次被触发，则重新计时。只有当事件停止触发，并且超过了设定的延迟时间后，回调函数才会被执行一次。

通俗理解：就像电梯关门，有人进来就重新计时，直到一段时间内没人进来，电梯才真正关门。

# 实现

/**
 * @description: 防抖函数
 * @param {Function} func 需要防抖的函数
 * @param {number} delay 延迟时间（毫秒），默认为200ms
 * @return {Function} 经过防抖处理的函数
 */    
function debounce(func, delay = 200) {
  let timer = null; // 利用闭包保存定时器ID

  return function(...args) {
    const context = this; // 保存函数执行时的this上下文
    // 清除上次还未执行的定时器
    if (timer) {
      clearTimeout(timer);
    }
    // 设置一个新的定时器，在延迟后执行func
    timer = setTimeout(() => {
      func.apply(context, args); // 使用apply确保this和参数正确传递
    }, delay);
  };
}

使用场景 避免重复

  1. 搜索框输入：用户连续输入时，只在输入停止后才发送请求，避免频繁查询。
  2. 表单提交/按钮点击：防止用户短时间内重复点击按钮，导致多次提交数据。
  3. 窗口resize：只在窗口停止调整大小后才执行布局计算，避免频繁重绘。
  4. 文档编辑时实时保存：只在用户停止输入一段时间后才触发保存操作。

# 节流（Throttle） 按时执行

# 定义

节流的核心思想是“按时执行一个有效指令”：在事件被触发后，设定一个固定时间间隔。在该时间间隔内，无论事件被触发多少次，回调函数都只会被执行一次。

通俗理解：就像技能冷却时间，技能释放后进入冷却，冷却期间无论怎么按都无法再次释放，直到冷却结束才能再次释放。

# 实现

/**
 * @description: 节流函数
 * @param {Function} func 需要节流的函数
 * @param {number} delay 延迟时间（毫秒），默认为200ms
 * @return {Function} 经过节流处理的函数
 */    
function throttle(func, delay = 200) {
  let timer = null; // 利用闭包保存定时器ID
  let startTime = Date.now(); // 记录上次执行时间

  return function(...args) {
    const curTime = Date.now(); // 当前触发时间
    const remaining = delay - (curTime - startTime); // 距离下次可执行时间还剩多少

    const context = this;
    // 清除上次还未执行的定时器（如果存在）
    if (timer) {
      clearTimeout(timer);
      timer = null; // 清除后置为null，避免影响下次判断
    }

    // 如果距离上次执行时间已超过delay，则立即执行
    if (remaining <= 0) {
      func.apply(context, args);
      startTime = curTime; // 更新上次执行时间
    } else {
      // 如果未到delay时间，则设置一个定时器，确保在delay后执行一次
      // 这样可以保证在事件停止触发后，最后一次事件也能被处理
      timer = setTimeout(() => {
        func.apply(context, args);
        startTime = Date.now(); // 定时器执行后更新时间
        timer = null; // 定时器执行后清空
      }, remaining);
    }
  };
}

使用场景 控制频率

  1. 鼠标滚动事件：例如页面滚动加载更多数据，每隔一段时间检查一次是否需要加载。
  2. 鼠标移动/拖拽事件：在地图拖拽、元素拖拽等场景中，限制事件处理函数的执行频率，避免卡顿。
  3. 游戏射击：限制子弹发射频率。
  4. 动画效果：控制动画帧率，保证动画流畅性。

# 节流和防抖的区别与联系 对比

联系

  1. 目的相同：两者都旨在优化性能，通过限制函数的执行频率来减少不必要的计算或网络请求。
  2. 实现基础：都利用了JavaScript的闭包特性来保存状态（如定时器ID、上次执行时间）。
  3. 应用场景：都适用于处理高频触发的事件。

区别

特性 防抖 (Debounce) 节流 (Throttle)
核心 延迟执行：事件停止触发后，等待一段时间再执行。 周期执行：在一段时间内，只执行一次。
执行时机 事件触发N秒后执行，若N秒内再次触发，则重新计时。 每隔N秒执行一次，无论期间触发多少次。
场景 搜索建议、表单验证、窗口resize、按钮防重复点击。 滚动加载、鼠标移动、拖拽、游戏射击。
效果 最终只执行一次。 在给定时间段内，至少执行一次，最多执行多次（取决于触发频率）。
